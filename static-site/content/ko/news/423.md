# 2026년 8월 블로그 (일본어 번역)

안녕하세요! 여름휴가에서 돌아왔습니다! 😎

여러분도 잠시 손을 놓고 재충전할 수 있었나요? 저는 여름휴가 동안 제 머릿속의 모든 틈새 시간을 빼앗아 간 “그 게임”의 개발에, 휴가 후부터 전일제로 매진할 만반의 준비를 하고 돌아왔습니다.

복귀하자마자 산더미 같은 다른 작업들이 방해하려 했지만…… 모두 쓰러뜨렸습니다. 이제 아무도 저와 이 “사랑스러운 작품” 사이를 방해할 수 없습니다!

## 진행한 작업 개요

- **콘텐츠 작성**
Java SDK가 추가되면서 튜토리얼 코드에 두 가지 큰 리팩터링이 이루어졌습니다:
`Symbol`: 먼저 모든 튜토리얼의 Java 버전이 만들어졌습니다. 무려 50개입니다 😬).
　
`Symbol`: 이어서 트랜잭션을 만드는 기존 튜토리얼이 지원 언어에서 정적 타입 디스크립터(statically typed descriptors)를 사용하도록 업데이트되었습니다. 이는 일반 객체에서 만드는 것보다 안전한 방식이며, 처음부터 이렇게 했어야 했습니다. 하지만 Python은 동적 타입 언어이므로 언어 간 코드가 너무 크게 벌어지는 것은 피하고 싶었습니다.
그렇기는 해도 Symbol Python SDK 최신 버전에서 우회 방법이 제공되어, 트랜잭션을 만드는 모든 튜토리얼(3개 언어로 약 40개 😬)에서 타입이 지정된 디스크립터(typed descriptors)를 사용할 수 있게 되었습니다.
　
 　이는 **상당한** 작업량이었고, 보통이라면 프로세스 후반에 할 내용은 아니었습니다. 하지만 작은 실험을 해 보고 싶어 코드 관련 작업 전체에 ChatGPT를 사용해 보았는데, 결코 완전히 자동으로 끝나는 일은 아니었습니다. 코딩 자체는 아마 2시간 정도에 끝났지만, 리뷰에는…… 꼬박 1주일이 걸렸고 꾸준한 수작업의 연속이었습니다. 그래도 전체적으로 이 실험의 결과는 꽤 훌륭했다고 생각합니다.
　
 　단점은 다시 완전히 지쳐서 또 한 번 휴가가 필요할 정도였다는 것입니다. 😂
　**물론**,……*또 하나의 프로젝트*가 없었다면 말입니다.

- **리뷰**
`NEM`: 여름휴가 직전 [Zero](https://github.com/zero4862) 가 몇 개의 풀 리퀘스트를 보내 주었고, 남은 문제를 수정하고 문서 전체를 다듬었습니다.

- **사이트 구성**
문서가 지원하는 언어에 Java가 추가되면서 뒤에서 더 많은 조정이 필요해졌지만, 약간의 궁리(그리고 엄청난 양의 Markdown)로 해결할 수 없는 일은 없었습니다.

## XYM City 3D

드디어 돌아왔어, 베이비! 🥹

몇 달 동안 쉬지 않고 문서 작성에 매달리면서도 게임 생각을 계속 머릿속 한쪽에 두고 있었습니다. 이번 여름휴가에는 노트 몇 권을 들고 PC에서 떨어져 지냈는데, 제 안에 쌓아 둔 “광기”를 한꺼번에 풀어낼 수 있었습니다. 😂

<img width="1324" height="612" alt="Image" src="../images/August2026_DocsBlogs_2.webp" />

이제 책상으로 돌아왔고 Symbol 문서도 거의 완료되어, 모든 메모를 정리한 게임 디자인 문서(GDD)에 쏟아붓고 있습니다. 아티스트와의 주간 회의도 다시 시작되었고, 각자의 작업을 마친 조직의 아티스트들이 속속 참여하고 있습니다. 예전에 함께 일했던 작곡가와 면담했는데, 그는 꼭 이 프로젝트에 참여하고 싶다고 말했습니다.

프로젝트가 마침내 속도를 내고 있어 앞으로의 전개가 정말 기대됩니다 🥹
게임은 아직 **아주 초기** 단계이며, ChatGPT로 생성한 초상화를 포함해 여기 있는 것은 모두 임시 소재이지만, 설레는 마음을 도저히 억누를 수 없습니다! 😄

<img width="737" height="770" alt="Image" src="../images/August2026_DocsBlogs_3.webp" />

아티스트들이 “무엇부터 시작하면 좋을까요?”라고 묻기 시작해서, 스토리와 미션, 대화 집필을 정말 진행하고 싶지만 최우선으로 에셋 파이프라인 구축에 힘쓰고 있습니다. 미션 개요를 입력하면 필요한 에셋 목록이 출력되고, 아티스트, 뮤지션, 작가, 3D 모델러가 Notion을 열어 필요한 것을 확인하고 바로 작업에 착수할 수 있는 구조입니다.

그러고 보니 저는 목록 만들기를 좋아한다고 전에 말씀드렸죠 😄
