# 2026年8月のブログ（日本語訳）

ごきげんよう！夏休みから帰ってまいりました！😎

皆さんは少し手を休めリフレッシュできましたか？ 私は夏休みの間、私の頭の中のからありとあらゆる隙間時間を奪い去った「あのゲーム」の開発に、休み明けからフルタイムで取り組む準備を万端にして戻ってきました。

復帰早々、他の山積みのタスクが邪魔をしようとしてきましたが……すべてなぎ倒しました。もう誰も、私とこの「愛しき作品」の間を邪魔できる者はいません！

## 行った作業の概要

- **コンテンツ執筆**
Java SDKの追加に伴い、チュートリアルコードで2つの大きなリファクタリングが実施されました：
`Symbol`：まず、全チュートリアルのJava版が作成されましたその数なんと50個😬）。
　
`Symbol`：続いて、トランザクションを作成する既存のチュートリアルが更新され、対応言語において静的型付け記述子（statically typed descriptors）を使用するようになりました。これはプレーンなオブジェクトから作成するよりも安全な仕組みであり、最初からそうしておくべきでした。しかし、Pythonは動的型付け言語であるため、言語間でコードがあまりに懸離してしまうのを避けたかったのです。
とはいうものの、Symbol Python SDKの最新バージョンで回避策が提供されたため、トランザクションを作成するすべてのチュートリアル（3言語で約40個 😬）で型定義された記述子（typed descriptors）が使用できるようになりました。
　
 　これは**相当な**作業量であり、通常であれば終盤のプロセスで行うような内容ではありませんでした。ですが、ちょっとした実験をしてみたいと思い、コード関連のタスクすべてにChatGPTを使ってみたのですが、それは決して完全に自動で済むようなものではありませんでした。 コーディング自体はたおそらく2時間ほどで終わりましたが、レビューには……実に丸1週間を要し、地道な作業の連続となりました。ですが全体として、この実験の結果はかなり素晴らしいものだったと感じています。
　
 　デメリットといたしましては、またしても完全に疲れ果ててしまい、もう一度休暇が必要になってしまうほどだったことです。 😂
　**もっとも**、……*もうひとつのプロジェクト*がなかったならば、の話ですが。

- **レビュー**
`NEM`：夏休みに入る直前、 [Zero](https://github.com/zero4862) がいくつかのプルリクエストを送信してくれて、残っていた問題の修正とドキュメント全体のブラッシュアップがなされました。

- **サイト構成**
ドキュメントが対応する言語にJavaが加わったことにより、裏側での調整がさらに必要になりましたが、ちょっとした工夫（と膨大な量のMarkdown）で解決できないことは何もありませんでした。

## ドキュメンテーションの進捗状況

**Symbol**
マルチシグ操作に関するモバイルウォレットのユーザーガイドを残すのみです。

**NEM**
計画していたNEMのチュートリアルは前回のブログでお伝えした通りすべて完了しました。あとはSymbolのドキュメントで同じ作業をした後、息が整い次第Java版を追加するだけです。

## XYM City 3D

ベイビーついに戻ってきたよ！🥹

ここのところ何か月もゲームのことをずっと頭のどこかで考えながら、休む間もなくドキュメント作成に取り組んできました。そしてこの夏休み中、数冊のノートを手にしてPCから離れて過ごしたのですが、私の内に溜め込んでいた「狂気」を一気に解き放つことができました。 😂

<img width="1324" height="612" alt="Image" src="../images/August2026_DocsBlogs_2.webp" />

そしてデスクに戻った今、Symbolのドキュメントもほぼ完了したので、すべてのメモを整理したゲームデザインドキュメント（GDD）へと注ぎ込んでいるところです。アーティストとの週次ミーティングも再開され、それぞれのタスクを終えた組織内のアーティストたちが続々と参加してくれています。過去に一緒に仕事をした作曲家の方に面談したのですが、彼は是非このプロジェクトに参加したいと言ってくれました。

プロジェクトがいよいよ加速してきましたので、この先の展開が本当に楽しみです🥹
ゲームはまだ**ごく初期**の段階で、ChatGPTで生成したポートレートも含め、ここにあるものはすべて仮素材なのですが、はやる気持ちをどうしても抑えきれません！ 😄

<img width="737" height="770" alt="Image" src="../images/August2026_DocsBlogs_3.webp" />

アーティストたちからは「何から手を付ければ良い？」と聞かれはじめているので、ストーリーやミッション、会話の執筆を本当は進めたいところですが、最優先事項としてアセットパイプラインの構築に取り組んでいます。ミッションの概要を入力すれば、必要なアセットの一覧が出力され、アーティスト、ミュージシャン、ライター、3DモデラーたちがNotionを開いて何が必要かを確認し、すぐに作業に取りかかれる……そんな仕組みです。

そういえば私はリストを作るのが好きだと以前お伝えしましたね😄
