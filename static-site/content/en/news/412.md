# July 2026 Blog (Japanese Translation)

Greetings, everyone!

Summer is finally in full swing. Before I take a short summer break, here is an update on my progress.

I continued to be busy creating documentation this month, but as a result, several long-running projects have finally been completed. Do you remember when I said that I like making lists? There is something I like even more than making lists: **crossing items off a list**. 😈

So, here is what I worked on in July.

## Overview of the work completed

- **Content writing**
In July, I continued creating the [Symbol mobile wallet documentation](https://docs.symboltest.net/en/userbook/mobile-wallet/intro/). Several new user guides covering common wallet operations, such as sending mosaics, deleting accounts, and other everyday tasks, were added. Only the guide for multisig accounts remains.

  Another important milestone this month was adding documentation about “Symbol Bridge” to the [textbook](https://docs.symboltest.net/en/textbook/bridge/) and the [user guide](https://docs.symboltest.net/en/userbook/mobile-wallet/bridge-tokens/). These explain the overview of Symbol Bridge and how assets move between Symbol and Ethereum. Since this is an area involving entirely different ecosystems, it was a very interesting experience to document the concepts that go beyond the boundaries of each core blockchain and lead to cross-chain interoperability. 😊

  Regarding NEM, I updated the [node installation guide](https://docs.nemtest.net/en/userbook/node/install/) and the [registration guide for the supernode program](https://docs.nemtest.net/en/userbook/node/supernode-program/). Some parts of the previous guides needed corrections, so they were migrated to the new NEM documentation site.
  
- **Review**
 [Zero](https://github.com/zero4862) continued working at an incredible pace to complete the remaining NEM developer tutorials by summer, while I desperately tried to keep up with him and catch up on reviews. And the good news is... he did it! Once I finish the final three reviews, all the planned tutorials will be complete.
 
- **DARUMA STUDIO**
Although creating documentation remained the main focus, the weekly brainstorming sessions for “XYM City 3D” have become something special that I can no longer do without. We made some progress defining the game’s art direction and formally compiled it into a game design document. I hope you look forward to it 😊

- **Site structure**
It rarely makes headlines, but I carried out the usual behind-the-scenes improvements to keep the documentation project healthy. These included fixing CI and linting issues, updating build dependencies (which, amazingly, reduced build time by 30%!), and fine-tuning the CSS for the REST API and image captions. We also made further progress preparing to launch the new documentation site. We deployed redirects, updated links, and... finally removed the “WIP (work in progress) 🚧” label from the site 🎉
