# 2026年7月博客（日文翻译）

大家好！

盛夏终于到来了。在短暂休假之前，先向大家汇报一下进展。

本月我仍然忙于文档编写，不过也因此，几个长期推进的项目终于完成了。还记得我以前说过喜欢列清单吗？比制作清单更让我喜欢的事情，是 **在清单上划掉并删除项目**。😈

下面介绍一下我在7月进行的工作。

## 已完成工作的概要

- **内容撰写**
7月我继续编写 [Symbol 移动钱包文档](https://docs.symboltest.net/en/userbook/mobile-wallet/intro/)。我们新增了几份用户指南，涵盖发送马赛克、删除账户以及其他日常操作等常见的钱包操作。现在只剩下多重签名账户相关的指南了。

  本月另一个重要的里程碑，是在[教科书](https://docs.symboltest.net/en/textbook/bridge/)和[用户指南](https://docs.symboltest.net/en/userbook/mobile-wallet/bridge-tokens/)中加入关于“Symbol Bridge”的文档。这些文档介绍了 Symbol Bridge 的概要，以及资产如何在 Symbol 和以太坊之间转移。由于这是涉及完全不同生态系统的领域，能够记录从各个核心区块链的边界延伸到跨链互操作性的概念，是一次非常有趣的经历。😊

  关于 NEM，我更新了[节点安装指南](https://docs.nemtest.net/en/userbook/node/install/)和[超级节点计划注册指南](https://docs.nemtest.net/en/userbook/node/supernode-program/)。由于之前的指南有几处需要修正，因此已迁移到新的 NEM 文档网站。
  
- **评审**
 [Zero](https://github.com/zero4862) 继续以极快的速度工作，争取在夏天前完成剩余的 NEM 开发者教程，而我也拼命追赶他的进度并努力跟上评审。好消息是……他做到了！只要我完成最后三项评审，计划中的教程就全部完成了。
 
- **DARUMA STUDIO**
虽然文档编写仍然是工作的重点，但“XYM City 3D”的每周头脑风暴会议已经成为不可或缺的特别活动。我们在确定游戏艺术方向方面取得了一些进展，并将其正式整理成了游戏设计文档。希望大家期待它的后续发展 😊

- **网站结构**
这些工作很少成为新闻头条，但为了保持文档项目的健康运行，我一如既往地进行了幕后改进。包括修复 CI 和代码检查问题、更新构建依赖项（结果令人惊讶，构建时间缩短了30%！），以及微调 REST API 和图片标题的 CSS。我们还进一步推进了新文档网站上线的准备工作。部署重定向、更新链接，然后……终于从网站上删除了“WIP（进行中）🚧”标签 🎉
