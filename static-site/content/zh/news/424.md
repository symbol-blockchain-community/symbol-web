# 2026年8月博客（日语译文）

大家好！我从暑假回来了！😎

大家有没有稍微放下工作、好好恢复精神呢？在暑假期间，我已做好万全准备，假期一结束便全职投入开发“那款游戏”——它夺走了我脑中每个角落的所有零碎时间。

刚回来，堆积如山的其他任务就想妨碍我……但我把它们全都推倒了。现在已经没有人能挡在我和这件“心爱作品”之间！

## 已完成工作的概述

- **内容编写**
随着 Java SDK 的加入，教程代码进行了两项大型重构：
`Symbol`：首先，所有教程都创建了 Java 版本，足足有 50 个 😬）。
　
`Symbol`：随后，现有的创建交易教程已更新为在支持的语言中使用静态类型描述符（statically typed descriptors）。这比通过普通对象创建更安全，本来就应该从一开始这样做。不过，Python 是动态类型语言，所以我想避免各语言之间的代码差异过大。
不过，Symbol Python SDK 的最新版本提供了变通方法，因此现在所有创建交易的教程（3 种语言约 40 个 😬）都能使用类型化描述符（typed descriptors）。
　
 　这是一项**相当大**的工作量，通常不会在流程后期才做。但我想做一个小实验，于是对所有与代码有关的任务都使用了 ChatGPT；这绝不是完全自动完成的。编码本身大概花了两小时，但审查……整整花了一周，是持续而细致的工作。不过总体来说，我觉得这项实验的结果相当不错。
　
 　缺点是我又一次精疲力竭，甚至需要再休一次假。😂
　**不过**，……前提是没有*另一个项目*。

- **审查**
`NEM`：暑假前不久，[Zero](https://github.com/zero4862) 发送了几个拉取请求，修复了剩余问题并完善了整体文档。

- **网站结构**
随着文档支持的语言中加入 Java，后台还需要更多调整，但只要有一点巧思（和海量 Markdown），没有什么问题不能解决。

## XYM City 3D

宝贝，我终于回来了！🥹

这几个月来，我一直在不停地编写文档，同时总在脑海某处想着游戏。这个暑假，我带着几本笔记本离开电脑，终于一次性释放了积压在内心的“疯狂”。😂

<img width="1324" height="612" alt="Image" src="../images/August2026_DocsBlogs_2.webp" />

现在我回到书桌前，Symbol 文档也几乎完成了，所以正把所有笔记投入整理好的游戏设计文档（GDD）。与艺术家的每周会议也重新开始，完成各自任务的组织内艺术家正陆续加入。我与过去合作过的一位作曲家见面，他说非常想参与这个项目。

项目终于开始加速，我非常期待接下来的发展🥹
游戏仍处于**非常早期**的阶段，包括由 ChatGPT 生成的肖像在内，这里的所有内容都只是临时素材，但我实在按捺不住兴奋之情！😄

<img width="737" height="770" alt="Image" src="../images/August2026_DocsBlogs_3.webp" />

艺术家们开始问“该从哪里着手？”，所以尽管我很想推进故事、任务和对话的写作，眼下最优先的是建设资产管线。输入任务概要后就会输出所需资产清单，艺术家、音乐家、作家和 3D 建模师可以打开 Notion，确认所需内容并立即开始工作。

对了，我之前说过我喜欢列清单😄

暑假结束，9 月开始了，但看来我已经忘记如何放慢速度 😄

- `Mobile`：功能实现完成后，完成移动钱包用户指南。
