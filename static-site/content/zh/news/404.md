# 2026年6月博客（日文翻译）

早上好！
这个月在暑假前还有堆积如山的事情要做，所以先简单更新一下近况！
文档编写工作终于逐渐稳定下来，我总算为 XYM City 挤出了一点时间。虽然没有获得预想中的那么多时间，但还是有一些小进展可以与大家分享，希望大家喜欢。

## 已完成工作的概览

- **内容编写**
新的 Symbol 移动钱包的开发终于到了可以开始编写指南的阶段，所以我马上开始动笔了。界面本身非常直观易懂，因此大多数用户可能并不需要指南，但与其之后后悔没有提前准备，现在先准备好总是更好。

- **审核**
**开发者页面**(task-docs-dev)
[Zero](https://github.com/zero4862) 目前正在全职制作新的 NEM 文档网站，新页面不断增加，速度快到我几乎来不及审核了 😄
这个 NEM 开发者教程以 Symbol 的教程为基础，并使用 Symbol SDK，因此进展非常快。不是开玩笑，真的很快！欢迎查看[当前列表](https://docs.nemtest.net/en/devbook/intro/)。

- **DARUMA STUDIO**
6月一开始，我们就充满干劲地投入了 XYM City 的游戏开发。几个月来文档编写一直不停，相信大家都能想象我有多么渴望开发游戏！
但很快就清楚了：要在暑假前完成文档，还需要最后再努力一把，因此愉快的一周游戏开发又不得不暂时中断。关于我们成功推进的工作，请参阅下面的 XYM City 报告。

- **管理**
这是每月都会出现、无法回避的例行事务。这次我估算了将新 NEM 教程中的改进部分移植回原始 Symbol 教程所需的工作量，并制作了 Symbol 移动钱包指南的清单。
不过另一方面，我很喜欢制作清单。往积极的一面看，正因为有了这份清单，我才能画出下面这幅精彩的情节图 😄

- **网站结构**
⚙️ 经过在[这个拉取请求](https://github.com/symbol/symbol/pull/1505)上长达一年多的工作，我们终于准备好将新的文档分支合并到 Symbol 单体仓库的主开发分支了 🎉
其中大部分是维护工作：调整以符合全局仓库的 lint 规则、删除旧的 docs 文件夹，以及将文档纳入构建流程。不过，能找个理由暂时放下拼写检查器、写一点代码，我随时都很欢迎。😊
☕ 由于 Java SDK 正在开发中，我们重新启用了文档网站的 Java 支持。这从一开始就是计划中的内容，因此没有出现特别的问题。
新的 NEM 文档网站目前也仍在建设中，所以其基础设施还需要定期微调。

- **学习**
🤖 不管喜欢还是不喜欢，LLM 技术已经扎根，因此我也会继续探索。最近几天我一直在使用名为 [Pi](https://pi.dev/) 的本地环境进行各种尝试；如果有机会，我强烈建议大家也试试类似的工具。你会对语言模型究竟是什么，以及我们应该如何与它互动，获得宝贵的洞察。

## 文档进展情况

**Symbol**
Symbol 文档已正式完成 😄。目前只剩下为移动钱包补充用户指南。

**NEM**
我原本预计 NEM 文档的进展会比 Symbol 更快，但没想到会快到这种程度。
计划中的 NEM 开发者教程已经完成了 75%，上个月还是 25%。
此外，NEM Textbook 也已经完成，并且已经通过了 Jaguar 的审核。

<img width="367" height="241" alt="Image" src="../images/June2026_DocsBlogs_2.webp" />

## XYM City
目前我们仍主要在制定游戏设计文档（GDD），专注于具体化游戏的核心主题。这个主题是支撑项目其他所有要素的基础。例如，为了让所有设定和发展保持一致，我们不仅记录主要角色，也记录包括普通 NPC 在内的每个人为什么会出现在这座城市。

除此之外，我们还详细写下了所有游戏机制。无论是负责实现这些机制的开发者（大概是我），还是利用它们制作任务的任务设计师（应该也是我），都能以实际有用的方式使用这些内容。

不过，这些工作比较朴素。真正令人兴奋的，还是头脑风暴中的创意构思环节 😄

Syndicate 的新 3D 建模师 Chris 加入了每周会议。这样一来，除了 Reid 正在推进的概念艺术之外，我们很快也能与大家分享角色模型了。

顺便说，Reid 现在正在绘制城市的平面图。这样我们终于能掌握整个项目一直缺少的尺度感。

<img width="1594" height="1202" alt="Image" src="../images/June2026_DocsBlogs_3.webp" />

由此产生了我们目前称为“黄色地区”的区域的第一个建筑概念（详细内容暂时保密 😈）。

<img width="1704" height="970" alt="Image" src="../images/June2026_DocsBlogs_4.webp" />

我实在等不及了，所以直接以这个概念为基础先行推进。使用游戏引擎和地图工具，我们已经完成了该地区第一个街区的初步搭建（灰盒）。

<img width="1590" height="991" alt="Image" src="../images/June2026_DocsBlogs_5.webp" />

搭建初步模型的目的是了解城市的尺度。具体来说，我们会验证：“尺度是否合适？”“街道是否太窄，或者反过来太宽？”“建筑高度是否合适？”“是否有足够空间放置所有想实现的元素？”最重要的是，我们要判断：想象在这座城市中漫步会不会很有趣，还是会觉得移动很麻烦。这也包括验证能否通过跳跃屋顶来移动等游戏玩法。

当然，现在得出这些问题的结论还为时过早，但这就是目前我的周末安排 😋

## 接下来的计划

- 继续审核 Zero 的 NEM 文档工作
- 完成 Symbol 文档分支合并到主开发分支的工作
- 添加 Symbol 移动钱包用户指南
- 继续每周的游戏头脑风暴会议；如果时间充裕，还将制作和修改游戏设计文档（GDD）
- 🌞 开始暑假！8月我会休几天假，带着笔记本（纸质的）而不是笔记本电脑躲到乡下去。上次这么做时我完成了《Astra Ignota》，所以我也非常期待这次旅行！😄

感谢你读到这里。下个月再见！
