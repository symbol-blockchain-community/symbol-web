# 2026年8月部落格（日文譯文）

大家好！我從暑假回來了！😎

大家有沒有稍微休息並恢復精神呢？暑假期間，我為開發「那款遊戲」做好了萬全準備；它奪走了我腦中每個角落的所有零碎時間，所以假期一結束我便能全職投入。

剛回來時，堆積如山的其他任務想要妨礙我……但我把它們全都推倒了。現在已經沒有人能擋在我和這件「心愛作品」之間！

## 已完成工作的概要

- **內容撰寫**
隨著 Java SDK 的加入，教學程式碼進行了兩項大型重構：
`Symbol`：首先，所有教學都建立了 Java 版本，足足有 50 個 😬）。
　
`Symbol`：接著，既有的交易建立教學已更新為在支援的語言中使用靜態型別描述子（statically typed descriptors）。這比從普通物件建立更安全，本來就應該從一開始這樣做。不過 Python 是動態型別語言，因此我想避免各語言之間的程式碼差異過大。
話雖如此，Symbol Python SDK 的最新版本提供了因應方法，因此現在所有建立交易的教學（3 種語言約 40 個 😬）都能使用型別化描述子（typed descriptors）。
　
 　這是**相當大**的工作量，通常不會在流程後期才進行。不過我想做個小實驗，所以所有與程式碼有關的任務都使用了 ChatGPT；這絕不是完全自動完成的。編碼本身大概花了兩小時，但審查……整整花了一週，是持續而細緻的工作。不過整體來說，我認為這項實驗的結果相當出色。
　
 　缺點是我又一次完全筋疲力盡，甚至需要再放一次假。😂
　**當然**，……前提是沒有*另一個專案*。

- **審查**
`NEM`：暑假前不久，[Zero](https://github.com/zero4862) 送出了幾個提取要求，修正了剩餘問題並潤飾了整體文件。

- **網站結構**
文件支援的語言加入 Java 後，幕後需要更多調整，但只要有一點巧思（和海量 Markdown），沒有什麼問題不能解決。

這是本月各項任務的相對時間分配：

## 文件進度

**Symbol**
只剩下關於多重簽章操作的行動錢包使用者指南。

**NEM**
如同前一篇部落格所說，計畫中的 NEM 教學已全部完成。接下來只需在 Symbol 文件完成相同工作，喘口氣後再加入 Java 版本。

## XYM City 3D

寶貝，我終於回來了！🥹

這幾個月來，我不停撰寫文件，同時總在腦海某處想著遊戲。這個暑假，我帶著幾本筆記本離開電腦，終於能一次釋放積壓在內心的「瘋狂」。😂

<img width="1324" height="612" alt="Image" src="../images/August2026_DocsBlogs_2.webp" />

現在我回到書桌前，而 Symbol 文件也幾乎完成，所以正把所有筆記投入整理好的遊戲設計文件（GDD）。與藝術家的每週會議也重新開始，完成各自任務的組織內藝術家正陸續加入。我和過去合作過的一位作曲家面談，他說非常想參與這個專案。

專案終於開始加速，我非常期待接下來的發展🥹
遊戲仍在**非常早期**的階段，包括由 ChatGPT 產生的肖像在內，這裡的一切都只是暫用素材，但我實在按捺不住興奮！😄

<img width="737" height="770" alt="Image" src="../images/August2026_DocsBlogs_3.webp" />

藝術家們開始問「該從哪裡著手？」，所以雖然我真的很想推進故事、任務和對話的撰寫，眼下最優先的是建立資產管線。輸入任務概要後便會輸出所需資產清單，藝術家、音樂家、作家與 3D 建模師能開啟 Notion、確認所需內容，並立即開始工作。

對了，我以前說過我喜歡列清單😄

## 下一步計畫

暑假結束，9 月開始了，但看來我已經忘記如何放慢速度 😄

本月目標是：

- `NEM`：審查撰寫這篇部落格時收到的開發者手冊日文譯文。
- `NEM`：加入 Java 版教學。
- `Mobile`：功能實作完成後，完成行動錢包使用者指南。
- `XYM City:`：全速前進！

感謝各位讀到這裡。下個月再見！
